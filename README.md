# 🛒 বাজার দর (BazarDor)

BazarDor is a web application that helps users check the prices of essential daily products in one place. Users can explore product categories, compare prices, and see which products have increased or decreased in price.

## 📌 Project Description

BazarDor is designed to make daily market price information easier to access. It provides a simple and responsive interface where users can browse products, view product details, and explore price changes. Users can also create an account, sign in, and manage their profile.

## 🛠️ Technologies Used

- **Next.js** – React framework for building the web application
- **React** – For building user interfaces
- **TypeScript** – For type-safe development
- **Tailwind CSS** – For responsive styling
- **DaisyUI** – For UI components
- **Better Auth** – For user authentication
- **React Toastify** – For notifications and feedback
- **Programming Hero API** – For product and category data
- **MongoDB** – For storing user and authentication data

## ✨ Key Features

1. **Product Price Overview** – View essential products and their current prices.
2. **Price Changes** – Explore products whose prices have increased or decreased.
3. **Product Categories** – Browse categories such as rice, lentils, oil, vegetables, fish, meat, eggs, and spices.
4. **Product Details** – View product information, price summaries, and market-specific prices where available.
5. **Authentication and Profile Management** – Sign up, sign in, and manage profile information.

## 📱 Responsive Design

The application is designed to work across mobile phones, tablets, and desktop screens.

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm
- Git

### Installation

1. Clone this repository or download the project.
2. Open the project folder in your terminal.
3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open [http://localhost:3000](http://localhost:3000) in your browser.
